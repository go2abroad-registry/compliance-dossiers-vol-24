主管税务局

萨摩亚税收局（SRA）是根据《2017年萨摩亚税收局法》设立的统一国家税收与海关机构；纳税人门户网站为：SRA电子服务/MySRA，网址为www.sra.gov.ws。国际公司的相关监管机构包括：商业、工业与劳动部下属的国际公司注册处，以及萨摩亚中央银行（负责外汇管制）。

外汇管制与央行政策诊断

经常项目兑换自由度

萨摩亚塔拉货币（WST，ISO 4217）是一种部分可兑换的管理货币。经常账户交易可通过CBS授权的授权经销商进行，只需提供相关的贸易文件和外汇管制文件即可；而居民公司进行的资本账户交易则需要事先获得CBS的批准，除非有有效的国际公司豁免规定。符合条件的国际公司可以通过其授权经销商在外汇管制豁免下发放股息和汇回资本，无需每次交易都经过CBS的审核，但需满足以下条件：有效的外汇管制豁免证书、没有萨摩亚居民实益所有者、经审计的财务报表，以及董事的偿付能力和资金来源声明。WST是一种在萨摩亚境外无法实物交付的货币，因此所有跨境药品交易都通过代理银行以美元或欧元进行结算，而WST仅用于当地运营费用。

出口外汇强制结汇要求

对于非豁免的萨摩亚居民出口商，外汇管制规定要求在收到款项后30天内缴存：出口所得的100%外币收入必须向获准经销商（CBS授权经销商）提交并按现行交易汇率兑换为萨摩亚塔拉（WST），除非CBS事先以书面形式批准延期。符合条件的国际公司，若仅从事离岸API批发业务，通常可免除强制兑换义务，可将出口收入存入授权经销商指定的境外外币账户，但前提是出口商品不源自萨摩亚境内商品，且银行须每年向CBS报告累计账户余额。非豁免交易的法定兑换比例为总收入的100%，扣除经核实的运费、保险费及直接销售佣金。

央行监管: 萨摩亚中央银行（Samoan: Faletupe Tutotonu o Samoa）——根据1984年《萨摩亚中央银行法》设立，并依据1977年《外汇管制法》及1980年《外汇管制条例》（经修订）授权的唯一货币、外汇管制及银行监管机构。萨摩亚中央银行对所有获许可的商业银行实施授权经销商监管，并管理适用的国际公司外汇管制豁免工具，该工具在保留萨摩亚中央银行报告与执法管辖权的前提下，放宽了符合条件的萨摩亚国际公司的外汇管制审批要求。

入资和股东贷款资金通过SWIFT MT103方式汇入ANZ或BSP的IC美元账户。这些资金带有符合BPM6标准的用途代码，用于向直接投资企业注入资本或来自直接投资者的贷款。第72栏中需填写萨摩亚IC注册号，第59栏中则填写IC的法定名称。接收方授权经销商需提交以下文件以验证资本流入：授权分配股份或提取贷款的董事会决议；已签署的贷款协议或认购文件；有效的IC外汇管制豁免证明；完整的KYC/EDD文件；以及资金来源说明——之后，资本托管账户将自动入账，无需单独获得CBS的同意，因为该IC不属于居民外汇管制范围。第一笔入账资金将触发银行的账户激活审核以及交易监控程序的开始。与外国API供应商的贸易结算通过SWIFT MT103直接转账方式完成（对于高价值款项，则使用MT202 COV方式），资金以美元或欧元从IC的操作账户通过银行的全球代理网络进行划转。对于大型已确认订单，标准清算方式为由ANZ/BSP开具的不可撤销的即期商业信用证（SWIFT MT700），并由全球前50大银行（如汇丰银行、BNP帕瑞巴斯或标准银行）进行确认。由于萨摩亚银行开立的信用证在海外受益人市场中的影响力有限，因此采用这种方式进行结算。根据UCP 600规定的文件提交要求，需包含商业发票、完整的清洁提单、分析证书以及GMP/WHO认证文件；所有基于SWIFT系统的美元清算业务均通过授权经销商的nostro账户进行，不允许通过无许可的金融科技渠道进行结算。即期外汇交易（T+2结算），由持有萨摩亚授权经销商牌照的机构办理，须遵守CBS交易报告及交易背景的真实性核实要求。针对已承诺贸易发票的即期远期合约（期限最长为12个月），在存在真实的美元/瓦斯特或美元/欧元商业敞口的前提下，经豁免的国际公司可在无需事先获得CBS批准的情况下予以批准。外币互换（固定对固定美元/瓦斯特或美元/欧元）须事先获得CBS书面批准，仅用于真实的资产负债表对冲，不得用于投机性头寸。以WST/USD为标的的离岸不可交割远期（NDF），仅通过获准的国际对手方在萨摩亚境外执行，且在萨摩亚不发生WST交割，以美元进行净额结算。通过银行的外汇部门记录的主要贸易货币（美元/欧元）的货币期权，其交易由向CBS提交的年度对冲有效性声明予以支持。

电商与网关结算适配度: 低等级——没有任何离岸数字支付服务或虚拟资产服务提供商获得在萨摩亚的许可或资格；《2007年反洗钱法》以及CBS的反洗钱/反恐怖融资指南规定，货币兑换和电汇业务只能由持牌银行及持牌资金输送机构进行。外国金融科技公司/数字支付服务公司只能作为辅助性的第三国收款或付款渠道在萨摩亚境外使用（例如，从买家处接收美元并支付给印度/中国的供应商），前提是不会持有或将资金转移到离岸账户；它无法满足IC保持其财政和资本托管账户在持牌萨摩亚授权经销商处的要求，而任何纯数字支付结构都会立即引发CBS的监管关注。

转让定价与经济实质

主文档/本地文档门槛: 在萨摩亚没有法定的本地文件/主文件阈值；1974年所得税法第59条授权税务专员对与非居民相关的非公平交易进行调整。对于年销售额超过200万瓦塔的药品原料批发业务，建议采用包含功能分析、基准研究以及定价政策的安全港文件体系。

经济实质审查范围: 萨摩亚尚未制定类似OECD标准的《经济实体规定》；然而，根据OECD有害税务行为论坛的承诺以及AML/CFT（企业）规则，注册代理必须核实该经济实体的经济目的，保持最新的实益所有权记录，并确认不存在任何国内萨摩亚商业活动。制药原料批发实体必须持有萨摩亚药品法规规定的有效批发/分销许可证，为每一原料供应链保存有效的银行和交易文件，并支付年度SIFA合规费用以保留其免税地位。

致命合规红线与董事个人责任

逃税 / 滥用税收豁免

法定制裁: 撤销第198条豁免的追溯效力；对所有未申报利润征收27%的企业所得税；处以最高达未缴税款150%的民事税罚

董事个人责任: 董事对未缴税款及罚款的返还承担连带和按份责任；税务欺诈行为构成犯罪的，最高可被判处七年监禁。
空壳公司 / 虚假或误导性的年度报告

法定制裁: 最高罚款达萨摩亚塔拉50,000元；强制注销该公司；10年内不得担任任何萨摩亚国际公司的董事

董事个人责任: 董事根据1987年《国际公司法》的犯罪条款，可能面临最高达25,000瓦斯特（WST）的个人罚款和最高三年的监禁。
反洗钱/药品许可违规

法定制裁: 罚款最高达10万瓦斯特兰岛元；扣押药品存货；取消注册代理人的许可证；移交萨摩亚反洗钱情报单位进行洗钱调查

董事个人责任: 根据2018年反洗钱法，董事可能面临禁止离境（旅行禁令）、冻结资产以及最高十年监禁的处罚。
年度报告及政府费用逾期

法定制裁: 迟报罚款；逾期金额按年利率10%计息；公司持续违约12个月后，将被行政注销并解散

董事个人责任: 在违约期间内，董事仍需就公司发生的债务根据适用于国际公司的欺诈性经营法理承担个人责任。
