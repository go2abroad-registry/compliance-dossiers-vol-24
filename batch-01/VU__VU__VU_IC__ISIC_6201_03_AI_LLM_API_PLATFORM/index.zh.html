电子政务申报门户

对于瓦努阿图国际公司（IC），不会颁发TIN或VAT号码。外国拥有的IC的办理流程如下：(1) 外国实益所有人聘请一个获得VFSC许可的注册代理；(2) 该代理提交公司章程/备忘录，并支付法定注册费（股东无需满足最低资本要求或居住要求）；(3) VFSC会颁发公司注册证书，上面载有IC的注册号，这是银行、Stripe系统接入以及合同中所使用的唯一法定识别码；(4) 由于IC依法免缴所得税、预扣税、资本收益税、印花税和VAT（《国际公司法》第222章），因此无需向VRA提交申请，也无需生成TIN；如果外国银行或交易平台要求提供税务证明，IC可从VFSC或其注册代理处获得确认免税的证书或状态函件，或者依靠与VFSC注册号相对应的ATI/外国税务表格。

外汇管制与央行政策诊断

经常项目兑换自由度

瓦努阿图瓦图货币（VUV）可以在经常账户和资本账户之间自由兑换。没有外汇管制法规，无需事先批准即可进行股息或利润汇款，非居民持有VUV/美元账户也不受限制。对于国际公司而言，资本账户自由化在法律上已经完全实现。实际摩擦主要源于同行银行的AML/OFAC筛查机制，以及集中在ANZ、BSP和BRED处的稀薄美元/瓦努阿图维拉尔迪货币市场流动性。对于那些收入以美元或USDC为计价单位的AI API平台而言，以美元计价的资金账户是其运营中的重点。

出口外汇强制结汇要求

没有任何强制要求。瓦努阿图没有规定的遣返时间限制，也没有强制性的转换比例要求，也不要求将出口收入或软件/API服务收入交还给RBV。国际公司可以将所有美元收益保留在境外账户中，无需遵守到期期限或VUV转换要求，但需符合各商业银行内部的严格审查标准。

转让定价与经济实质

主文档/本地文档门槛: 由于瓦努阿图没有转让定价法规，也没有用于保护的CIT基础，因此不存在法定门槛。法律上并未要求必须保存本地文件或主文件。根据OECD FHTP / BEPS同行评审标准，即使收入具有地域流动性，企业仍必须保留相应的公平价格记录；最佳实践要求：每年涉及相关方交易的金额超过50,000,000瓦努阿图元（约400,000美元）的，应通过转让定价政策、发票、合同、银行记录及相关文件进行记录。

经济实质审查范围: 在经合组织（OECD）有害税收做法论坛的同行评审以及瓦努阿图就国际税收与良好治理所作出的承诺背景下，从事服务业务（包括根据国际标准产业分类（ISIC）6201 规定的AI/LLM API平台）的国际公司，必须在瓦努阿图证明其经营活动与其实际业务规模相称的经济实质，具体包括：在瓦努阿图设立的实体办公场所、合格的员工或聘用的承包商、在瓦努阿图召开并管理的董事会会议、真实的运营支出，以及在瓦努阿图开展的核心收入产生活动。公司应将实质性的记录（如雇佣合同、董事会会议纪要、客户合同、发票、银行对账单）保存于注册代理人办公室，并每年更新；若未能妥善保存这些记录，该国际公司可能面临被撤销注册以及遭受不利的国际列名措施。

致命合规红线与董事个人责任

逃税 / 虚报

法定制裁: 最高可处以逃避税款或费用金额150%的罚款，法定罚款最高达50万瓦乌瓦（VUV）50万，没收未缴税款的所得，以及根据《国际公司法》（第190章）对国际公司（IC）实施注销或强制撤销。

董事个人责任: 董事（包括非居民）可能因虚假陈述而被个人追究刑事责任，被责令就税收损失作出民事赔偿，被禁止担任职务，并可能被监禁；在刑事调查期间，还可能被实施旅行禁令。
空壳公司 / 缺乏经济实质

法定制裁: 强制注销、撤销国际公司免税资格、依据《国际公司法》处以处罚，以及被欧盟/OECD不利分类；国际公司可能被取消登记，其资产将收归国家所有

董事个人责任: 揭开公司法人面纱：董事对未支付的义务及赔偿承担个人责任，被禁止管理公司，被从越南企业登记册中除名，并因自动信息交换机制而面临母国的税务追缴。
反洗钱/反恐融资

法定制裁: 瓦努阿图反洗钱/反恐融资框架下的刑事罚款、资产查封与没收以及监禁；当出现系统性缺陷时，注册代理人许可证的暂停或撤销、瓦努阿图金融情报单位的IC列入，以及金融行动特别工作组的监督

董事个人责任: 唯一的董事和股东需对反洗钱犯罪承担刑事责任：长期监禁、资产没收、旅行禁令、引渡风险，以及永久禁止在瓦努阿图或根据互助请求担任企业职务。
印花税与企业空壳滥用

法定制裁: 根据《印花税法》对印花税重新评估并加收罚金和利息，对欺诈行为处以罚款，撤销违规文书，以及由税务专员署（VFSC）发起的清算申请

董事个人责任: 董事须对受欺诈的债权人及税务机关承担民事责任；当公司实体仅具表面形式时，适用揭开公司面纱原则；对滥用公司形式进行欺诈的行为，可处以赔偿令、罚款及监禁。
