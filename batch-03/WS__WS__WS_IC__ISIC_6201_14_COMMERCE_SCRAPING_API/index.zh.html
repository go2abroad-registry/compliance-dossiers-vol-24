外汇管制自由度 萨摩亚塔拉货币（WST）并不具有自由兑换性。当有真实的发票、合同或经审计的财务报表作为支撑时，通过授权交易商商业银行进行账户支付通常是被允许的。资本账户交易，包括向国际公司注入外国股权，则需要事先获得CBS批准，或者通过持牌银行进行外汇管制声明。利润汇出过程中需要满足一系列条件：经审计的账目、CBS规定的外国汇款声明、来自萨摩亚国际金融局的证明其合规性的文件，以及银行内部决定，证明没有违反任何现行外汇管制规定。虽然国际公司可以享受免税待遇，但利润汇出仍然需要遵守反洗钱/反恐怖融资规定以及电汇合规审查要求。

电子政务申报门户

一家外国控股的国际公司（IC）通过萨摩亚许可的注册代理人，依据《2007年国际公司法》设立；国际公司注册局（商业、工业与劳动部）签发公司设立证书，而税收部自动分配税务识别号码（TIN）。该国际公司可获得标准政府费用证书，以替代税务申报；无需进行收入税登记或年度申报。如果该国际公司仅提供离岸API/代理服务，则无需进行VAGST注册；在特殊情况下，若从事经许可的境内应税活动，则必须向税收部提交VAGST商业注册表，并指定一个本地固定经营场所。

税号代号与申请路径: Tax_Exempt_Zone — 一家外国控股的国际公司（IC）通过萨摩亚许可的注册代理人，依据《2007年国际公司法》设立；国际公司注册局（商业、工业与劳动部）签发公司设立证书，而税收部自动分配税务识别号码（TIN）。该国际公司可获得标准政府费用证书，以替代税务申报；无需进行收入税登记或年度申报。如果该国际公司仅提供离岸API/代理服务，则无需进行VAGST注册；在特殊情况下，若从事经许可的境内应税活动，则必须向税收部提交VAGST商业注册表，并指定一个本地固定经营场所。

跨境出口 0% 零税率申报条件

在法定期限内，若货物实际出口至境外，或服务向境外居民提供并完全在萨摩亚境外实现实际效益，则经VAGST注册的出口商可享受零税率。若萨摩亚的IC向境外客户供应API数据管道、代理网关及爬虫基础设施，且服务在萨摩亚本地基础设施上提供，但接收方、合同履行地及经济利益均位于境外，则符合零税率条件；发票须以外币（通常为美元或USDC）向境外客户开具。

  • 通过ASYCUDA World（萨摩亚海关/财政部）提交的海关出口申报
  • 提单或航空运单，证明货物的实际出口
  • 汇入款项证明 / 银行信贷证明，显示外币收入
  • 与非居民对方签署的执行服务协议
  • 零税率VAGST税发票，用于确认非居民接收方
  • 离岸供应的技术证据（API访问日志、网关服务器记录、代理使用报告）

在萨摩亚，没有实时财政结算、数字印章或电子发票API的相关规定；纳税人需使用符合MfR标准的纸质/PDF发票，并通过MfR电子服务平台提交VAGST申报表。ASYCUDA World提供电子海关申报功能，但并不具备持续发票结算功能。

虚假或缺乏依据的零税率申报被视为《2012年税务管理法》和《2003年商品与服务税法》下的税收短少：MfR可追回已退还的VAGST，并加收利息，对故意逃避税款的行为可处以最高达200%的短少税罚款，以及对逾期金额征收每月滞纳金。明知是伪造的海关文件、虚假提单或虚构的汇款证明，将使董事面临刑事罚款和监禁，其公司注册资格被撤销，并在欺诈行为被证实的情况下，税务评估将无限期重新开启。

外汇管制与央行政策诊断

经常项目兑换自由度

萨摩亚塔拉货币（WST）并不具有自由兑换性。当有真实的发票、合同或经审计的财务报表作为支撑时，通过授权交易商商业银行进行账户支付通常是被允许的。资本账户交易，包括向国际公司注入外国股权，则需要事先获得CBS批准，或者通过持牌银行进行外汇管制声明。利润汇出过程中需要满足一系列条件：经审计的账目、CBS规定的外国汇款声明、来自萨摩亚国际金融局的证明其合规性的文件，以及银行内部决定，证明没有违反任何现行外汇管制规定。虽然国际公司可以享受免税待遇，但利润汇出仍然需要遵守反洗钱/反恐怖融资规定以及电汇合规审查要求。

出口外汇强制结汇要求

根据萨摩亚外汇管制法规，居民出口商必须在收到出口收入之日起30个日历日内，将其汇回萨摩亚的授权经销商银行。强制兑换比例必须为100%，以瓦东币形式进行兑换，除非萨摩亚中央银行授予特定的外币保留或豁免许可。对于国际公司而言，可以通过当地银行申请CBS豁免，但默认的法定时间和转换比例仍然为30天的退保规则以及100%的转换要求。授权经销商必须保留出口申报单、商业发票、提单或服务合同以及结算凭证，以便进行核查。

央行监管: 萨摩亚中央银行（CBS），依据1979年外汇管制法、1980年外汇管制条例以及1996年金融机构法运作

跨境清算通道与结算适配

inbound股权资本必须由海外母公司或投资者通过SWIFT MT103（或用于银行间交易时的MT202）方式，转账至萨摩亚授权的经销商银行，并存入专门的资本托管账户。汇款指令中必须注明萨摩亚国际公司的SIFA注册号、CBS外汇管制批准文件编号，以及符合BPM6直接投资——股权资本类别的用途说明。接收银行将在将资金从托管账户转入运营账户之前，核实关于资本发行的董事会决议、已认购股份清单、资金来源证明、良好状态证明，以及CBS外汇管制表格的签署情况。只有在获得CBS保留批准的情况下，外币才能被存放在允许以美元计价的账户中；否则则需按照当时有效的经销商银行汇率进行WST兑换。跨境贸易及许可款项应采用SWIFT MT103报文进行高频API许可结算，较大合同履约则应使用受《UCP600》及《ISBP 821》规则约束的商业信用证（MT700/MT710）。所有对外支付均需附有相应的商业合同、发票以及经授权的外汇兑换声明。萨摩亚银行将美元及第三货币支付通过代理行网络进行处理；萨摩亚塔拉（WST）并非国际清算货币，因此不存在直接的离岸WST清算渠道。对于以加密货币USDC计价的付款，国际公司须首先通过持牌交易所将USDC兑换为美元或欧元，再通过合规的SWIFT支付方式汇入受益人账户；银行不会处理以USDC计价的直接结算。以CBS许可的经批准的经销商记录的普通外汇远期合约，用于覆盖真实的已承诺贸易、API许可或经批准的资本项目敞口。期限匹配的外币债务或股权所得的跨境货币互换，须事先获得央行外汇管理批准，并提供完整的底层文件。短期外汇掉期用于对冲美元应收账款与WST或其他结算货币之间的营运资金错配。非交割远期合约在萨摩亚境内市场不可行，因为萨摩亚塔拉仍可通过授权经销商进行交割，且CBS并未设立经许可的非交割远期合约框架。
